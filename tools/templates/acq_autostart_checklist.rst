Граница безопасности
Копия Acquisition сохраняет исходную инициализацию и аппаратные записи.
Только телеметрия и Python-мост не управляют картами. Рабочий Acquisition
и копия не должны работать одновременно. HT, импульсы и установка не
запускаются; Supervision не должна выдавать команды включения.

Не запускать Main, Transport, TEST или Fixture отдельно. Старый WIP-проект

До запуска — оператор
1. Проверить безопасное состояние установки и возможность возврата к оригиналу.
2. На Everest: elyse/acquisition/telemetry должен быть ON. Это постоянный
   DS_AcqTelemetry/everest под Starter; не запускать второй приёмник.
3. На XP: C:\ACQ_SharedState_Python34_20261014\shared_state_receiver.pyw.
   Если мост уже работает, не запускать второй экземпляр. Иначе Start telemetry bridge.
4. Открыть Launch-проект в 32-битной LabVIEW 2012. При Missing VI или сломанной
   стрелке Run пробу не начинать. Открытие проекта само по себе VI не запускает.
5. Оператор штатно останавливает рабочий Acquisition и проверяет его завершение.
6. Оператор запускает только START_Acquisition_Telemetry.vi. Откроется панель
   копии Acquisition. Очереди создаются заранее; отправка работает параллельно.

Проверка
7. На XP растут accepted и everest_acknowledged; rejected остаётся 0.
   На Everest обновляются все 27 банков без ошибок чтения. Сравнить выбранные
   аналоговые/цифровые значения с PSP Supervision. Давление: VAM-A[10], [11], [20].
8. Проверить исходный UI и время цикла. Новый кадр Timeout-4 последовательно
   читает 27 локальных контролов, затем отдаёт снимок очереди. Сеть вынесена
   в отдельный Worker. Timeout 20 мс не гарантирует период доставки 20 мс.
9. Промежуточные снимки замещаются новыми. Хранится последнее значение в RAM,
   без истории и SQLite. Снимок не атомарен между картами; его время не является
   временем физического измерения. Зелёный ACK-индикатор не доказывает доставку.

Остановка
10. При stale, rejected, ошибках банков или задержке исходной логики прекратить пробу.
    Копию останавливает оператор штатной STOP-кнопкой Acquisition, с исходной
    деинициализацией. Не применять Abort для остановки машины.
11. После возврата Main Worker автоматически получает True и освобождает очереди.
    Если Worker не завершился, Stop telemetry transport останавливает только
    телеметрию; это не аварийный STOP установки. Последний снимок после остановки
    может остаться stale; гарантированной отправки финального кадра нет.
12. Оригинальный Acquisition запускать только после полного завершения копии.
    Ошибки создания очередей диагностировать отдельно: аппаратный Main не имеет
    нового блокирующего разрешения по готовности телеметрии.
